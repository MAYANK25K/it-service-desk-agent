# Access Management and Password Policy

Document ID: POL-SEC-004 | Owner: Security Office | Version: 2.1

## 1. Purpose

This policy controls how user accounts, passwords and system access are created, changed and removed.

## 2. Password Rules

- Passwords must have at least 14 characters.
- Passwords expire every 180 days.
- The last 10 passwords cannot be reused.
- MFA is mandatory for all accounts.

## 3. Password Reset Procedure

1. Ask the user to try the self-service reset portal first.
2. If that fails, the Service Desk must verify identity using the employee ID plus either an MFA push approval or confirmation from the user's line manager.
3. Never reset a password based on an email or chat message alone.
4. Give the user a temporary password that must be changed at first login.

## 4. Account Lockout

An account is locked after 5 failed login attempts. It unlocks automatically after 30 minutes, or the Service Desk can unlock it after identity verification.

## 5. Access Requests

Requests for new software or system access need approval from the user's line manager. Standard requests are fulfilled within 2 business days.

## 6. Privileged Access

Administrator rights need written approval from the Security Officer. Privileged access is time-boxed to 8 hours and every use is logged.

## 7. Offboarding

When HR notifies IT that an employee is leaving, all accounts must be disabled within 1 hour of the notice. Devices must be returned and wiped before reassignment.
